Grabox 説明書

最終更新日: 2026年9月3日

本書は，Grabox の使い方を手順の形で説明するものである．

個々の機能の要点は，アプリ内の「設定 → 機能の説明」にも同じ内容を置いてある．

1. 画面の構成

画面の下に 4 つのタブがある．

  • ブラウザ　ページを見て，保存したいものを探す場所．
  • ダウンロード　取得の進み具合を見る場所．
  • ライブラリ　保存し終えたものを使う場所．
  • 設定　動作を変える場所．

保存の作業は，おおむね「ブラウザで探す → ダウンロードで待つ → ライブラリで使う」と左から右へ進む．

2. 動画を保存する

1.　ブラウザタブでページを開く．アドレス欄に URL を入れるか，検索語を入れる．

2.　動画のあるページまで進む．一覧ページではなく，その動画の再生ページまで開くこと．

3.　画面下の「検出」を押す．

4.　そのページで配信されている動画・音声・画像の一覧が出る．

5.　保存したいものを選ぶ．画質が複数あるものは，ここで選べる．

6.　取得が始まる．進み具合はダウンロードタブで見られる．

取得はアプリを閉じても続く．終わると通知が出る．

履歴が保存できない状態では，ダウンロードを始められない．

2.1 一覧に何も出ないとき

次の順に試すとよい．

1.　ページを読み込み直してから，もう一度「検出」を押す．

読み込みが終わる前に押すと，まだ何も見つからないことがある．

2.　動画を数秒再生してから押す．

再生を始めて初めてアドレスが決まる配信がある．

3.　「デスクトップ表示」に切り替える．

画面下のメニューから選ぶ．スマートフォン向けの表示では出てこないものが，

パソコン向けの表示では見つかることがある．

4.　設定 → 高度な設定 → 「ページ内のネットワーク監視」を有効にする．

ページの通信を見て在りかを探すため，通常の検出で見つからないものが見つかる．

それでも出ない場合は，§4 の方法が使えることがある．

3. 保存したものを使う

ライブラリタブに並ぶ．

  • 押すと再生する．通信の無い場所でも再生できる．
  • 表示は一覧と格子を切り替えられる．ファイル名で検索もできる．
  • 項目を長押しするか選択すると，次の操作ができる．
  • 共有　他のアプリへ渡す．ファイルアプリへの保存にも使う．
  • 写真に保存　写真アプリへ書き出す．初回に許可を尋ねる．
  • 音声を書き出す　動画から音声だけを取り出す．元のファイルは残る．
  • 削除　消す．元に戻せない．

4. アドレスが取れない配信を保存する

一部のサイトは，動画を小片に分けて配信し，再生器の中で組み立てている．

この方式では掴めるアドレスが存在しないため，§2 の手順では保存できない．

このようなページでは，画面下のメニューに

「このページのメディアを収集 (blob:/MSE)」が出る．

4.1 手順

1.　ページを開いた直後に，まず収集を始める．

再生を進めてから始めると，途中までの分は入らない．

頭出しをしても，それ以降の収集物は捨てられず，頭出しした部分が穴として残る．

2.　動画を再生する．収集中は帯が出て，集まった量が表示される．

3.　そのページを開いたまま待つ． 再生が進んだ分だけ集まる．

4.　終わったら帯の「停止して保存」を押す．集めた分を捨てるなら「破棄」を押す．

4.2 知っておくべきこと

  • 実時間がかかる． 10 分の動画には 10 分かかる．収集中は再生を速めて短縮している．倍速と消音は設定 → 収集で外せる．既定は有効である．消音を外すと，通話中など他のアプリが音声を使うときに収集が止まることがある．
  • 他のアプリへ移ると止まる． 画面を消しても止まる．端末側がページの処理を止めるためで，避けられない．
  • 途中から始めると音声が入らないことがある． ページが既に別の形式を選んだ後だと， 音声を受け取れない．ページを開き直して最初から始めるほうが確実である．
  • 同時に 1 本だけ． 別の動画で始めると，前のものは打ち切られる．
  • タブを切り替えても続く． 収集は止まらない．ただしページを移動する・アプリを閉じる・他のアプリへ移ると止まる．
  • 暗号化されている配信は集められない． 検知した時点で集めた分を破棄する．

5. ライブ配信を録画する

配信中のものを選ぶと，録画するかを尋ねる．

設定 → ライブ録画の上限時間に達すると，そこで区切って保存する．

6. あとで取得を予約する

その場で保存できなかったページは，メニューの「あとで取得を予約」で控えておける．

アプリを開いている間，自動で取り直しを試みる．

7. 整理と容量

  • ストレージ管理（設定）　何にどれだけ使っているかを見る．不要なものを消せる．
  • ゴミ箱（設定）　記録との対応が切れて行き場を失ったファイルを 30 日間預かる． ライブラリで消したファイルはここを経由せず，その場で消える．
  • すべてのデータをエクスポート（設定）　保存済みファイルと一覧情報を Zip にまとめる． 端末を移すときに使う．

8. 通信量を抑える

  • Wi-Fi のみでダウンロード　有効にすると，Wi-Fi のときだけ取得する．
  • 同時ダウンロード数　既定は 3 本．1〜5 本，または無制限を選べる． 多くすれば速くなるとは限らない．失敗が増えるときは減らすとよい．

9. 広告を減らす

設定 → 広告ブロックを有効にすると，広告や計測のための読み込みを遮断する．

約 4 万件の規則を同梱している．

止められないものもある．動画の再生前や再生中に差し込まれる広告は，

動画そのものと同じ経路で配信されるため，読み込みを止める方式では区別できない．

サイトによっては表示が崩れることがある．その場合は無効にすること．

10. 保護

設定 → アプリロックを有効にすると，起動時と復帰時に Face ID / Touch ID で認証する．

保存したファイルと保存の履歴が隠れる．

11. うまくいかないとき

1.　ダウンロードタブの「失敗・キャンセル」を見る．

2.　失敗した項目を開くと，原因の説明が出る．

3.　「再試行」でやり直せる．

4.　さらに詳しく知りたいときは，項目の「この項目のログを見る」を開く．

記録は端末の中だけに残り，外部へ送られることはない．

アドレスは，クエリと資格情報を伏せてから保存される．ファイル名は伏せずにそのまま残る（開発者モードではアドレスも伏せない）．

開発者へ送るときは，設定の診断ログから共有する．

12. できないこと

正直に書いておく．

  • 保護された配信（DRM）の保存．　Netflix などの定額配信の作品は保存できない． 保護を回避する機能は持っていない．
  • 再生中に差し込まれる広告の遮断．　§9 のとおり．
  • 収集をバックグラウンドで続けること．　§4.2 のとおり．
  • webm・mkv の mp4 への変換．　この版では利用できない．変換に必要な部品を同梱していない． 対応する再生アプリで開くこと．

13. 使い方の約束

保存したものは，私的に楽しむ範囲で使うこと．

配布・公開は，権利者の許諾がない限り行わないこと．

各サイトの利用規約と法令を守ること．

詳しくは「利用にあたっての案内」を参照．
